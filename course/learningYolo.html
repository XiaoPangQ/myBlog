从零开始跑通 YOLO：环境搭建、图像检测、摄像头实时检测、边缘检测， 再到按项目需求改代码、训练自己的数据集。每一步都附常见问题与解决方法， 跟着操作一定能跑起来。

01 概念澄清与版本选型

先分清：目标检测 ≠ 边缘检测

很多人把"边缘检测"和"目标检测"混为一谈，这是上手前必须掰开的第一件事——它们回答的是完全不同的两个问题：

对比项 边缘检测（Canny / Sobel） 目标检测（YOLO）
回答的问题 "轮廓线条在哪" "是什么东西、在哪、有多少个"
输出 二值图（白线=边缘，黑=背景） 框 + 类别 + 置信度（person 0.92）
是否需要训练 不需要，纯数学算法 需要（用现成模型或自己训）
是否理解语义 不理解，只看像素梯度变化 理解，能区分手和猫
典型用途 轮廓提取、缺陷检测、图像预处理 安防监控、自动驾驶、人数统计
用什么库 OpenCV（cv2.Canny） ultralytics（YOLO）
📌 本指南的定位
YOLO 本身不做边缘检测，它是目标检测模型。本指南按「目标检测 YOLO」和「边缘检测 OpenCV Canny」两条线讲，最后再讲两者如何结合使用（比如 "YOLO 框出人 → 只对这个区域做边缘检测"）。

YOLO 是怎么工作的（30 秒版）

YOLO = You Only Look Once。传统算法把图片切成几千个小块分别判断，YOLO 则是把整张图一次送进神经网络，直接输出所有目标的框、类别和置信度，所以快——快到能实时处理视频流。 

 输入图像 ──► 缩放到 640×640 ──► 神经网络一次前向推理 ──► 输出所有检测结果
 (任意尺寸)      (letterbox)         (backbone+neck+head)      │
                                                              ▼
                                              [x1,y1,x2,y2] + class + conf
                                              例: person 0.92, car 0.87
                                                              │
                                                              ▼
                                                    NMS 去掉重复框 ──► 最终结果

版本怎么选

版本 发布方 状态 结论
YOLOv3 / v4 原作者 / 社区 老项目在用 新项目别选，仅读旧代码时了解
YOLOv5 Ultralytics 生态最成熟 大量老教程基于它，API 与 v8 类似
YOLOv8 / YOLO11 Ultralytics 当前主流 新项目首选，本指南以此为准
YOLOX / RT-DETR 其他团队 各有优势 有特殊需求再研究
💡 为什么选 ultralytics 这个库
不管是 YOLOv8 还是 YOLO11，都来自同一个团队 Ultralytics，安装同一个包 ultralytics，API 完全一致——学会一套代码，两个版本随便切换。网上 99% 的最新教程也都基于它。

模型规格怎么选（n / s / m / l / x）

模型 体积 速度 精度 mAP 适用场景
yolov8n（nano） ~6MB 最快 最低 入门学习、CPU、边缘设备
yolov8s（small） ~22MB 快 中 实时检测常用
yolov8m（medium） ~50MB 中 高 有 GPU 的常规项目
yolov8l / x 84MB+ 慢 最高 精度优先、离线分析

口诀：学习用 n，实时用 s，GPU 富余用 m，离线跑用 x。先用 yolov8n.pt 把流程跑通，再换大模型提升精度。

03 图像目标检测（Python 代码版）

CLI 一行命令虽然爽，但做项目必须会写代码——拿到每个框的坐标，才能做告警、计数、区域判断。

detect_image.py：完整可运行代码

# detect_image.py —— 图像目标检测
from ultralytics import YOLO

# 1. 加载模型（首次自动下载；yolov8n.pt 若已手动下载放同目录则直接用）
model = YOLO("yolov8n.pt")

# 2. 推理一张图片
results = model("bus.jpg", conf=0.5)  # conf: 置信度阈值，低于 0.5 的框丢弃

# 3. 遍历检测结果
for result in results:
    boxes = result.boxes          # 所有检测框
    for box in boxes:
        cls_id   = int(box.cls[0])              # 类别编号，如 0 = person
        cls_name = model.names[cls_id]        # 类别名，如 "person"
        conf     = float(box.conf[0])         # 置信度，如 0.92
        x1, y1, x2, y2 = box.xyxy[0].tolist() # 框坐标（左上角 x1,y1 + 右下角 x2,y2，像素）
        print(f"{cls_name} 置信度={conf:.2f} 坐标=({x1:.0f},{y1:.0f})-({x2:.0f},{y2:.0f})")

# 4. 保存画了框的结果图
annotated = results[0].plot()   # 返回 numpy 图像（BGR），已画好框和标签
import cv2
cv2.imwrite("result.jpg", annotated)
print("结果已保存到 result.jpg")

# bus 置信度=0.89 坐标=(23,230)-(797,486)
# person 置信度=0.92 坐标=(67,88)-(118,254)

结果对象详解（做项目必懂）

属性 含义 示例值
box.xyxy 框坐标 [x1, y1, x2, y2]，像素单位 [67.0, 88.0, 118.0, 254.0]
box.xywh 中心点 + 宽高 [cx, cy, w, h] 算区域中心时用它更方便
box.cls 类别编号（COCO 共 80 类） 0 = person, 5 = bus
box.conf 置信度 0~1 0.92
model.names 编号 → 类名字典 {0:'person', 1:'bicycle', ...}
results[0].plot() 返回画好框的图（numpy 数组） 直接 cv2.imwrite 保存

图像检测常见问题

现象 原因 解决方法
中文路径读不到图 / 报错 OpenCV 不支持中文路径 用 cv2.imdecode(np.fromfile(path, dtype=np.uint8), cv2.IMREAD_COLOR) 读，cv2.imencode + tofile 写（见第 4 章代码）
什么都没检测到 目标太小 / 置信度阈值过高 / 图像模糊 把 conf 降到 0.25 试试；小目标把 imgsz 调大到 1280
同一目标框了好几个框 NMS 阈值过松 推理时加 iou=0.45（默认 0.7，越小去重越狠）
检测到 80 类之外的东西 预训练模型只认识 COCO 80 类 自定义类别需要训练自己的模型（见第 10 章）
result.plot() 中文显示乱码 cv2 画框默认字体不含中文 自己用 cv2.putText 画英文，或用 PIL 的 ImageDraw 配合中文字体

04 图像边缘检测（Canny）

原理一句话 + 三步流程

边缘 = 像素值发生剧烈变化的地方。Canny 算法流程： 灰度化 → 高斯模糊去噪 → 计算梯度 → 双阈值筛选出边缘。 你只需要记住两个可调参数：threshold1（低于它的梯度被丢弃）和 threshold2（高于它的算强边缘，两者之间的看是否与强边缘相连）。 

 原图 ──► cvtColor 转灰度 ──► GaussianBlur 模糊 ──► Canny(t1, t2) ──► 边缘二值图
 彩色       3 通道→1 通道       去掉噪点细纹理        提取梯度变化         白线=边缘

edge_image.py：完整可运行代码

# edge_image.py —— 图像边缘检测（兼容中文路径）
import cv2
import numpy as np

def imread_zh(path):
    # OpenCV 原生 imread 不认中文路径，用 imdecode 绕过（Windows 必备）
    return cv2.imdecode(np.fromfile(path, dtype=np.uint8), cv2.IMREAD_COLOR)

# 1. 读图并转灰度
img = imread_zh("bus.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 2. 高斯模糊（核大小必须是奇数；模糊越强噪点越少，细节也越少）
blur = cv2.GaussianBlur(gray, (5, 5), 0)

# 3. Canny 边缘检测
edges = cv2.Canny(blur, threshold1=50, threshold2=150)

# 4. 保存（中文路径同样要用 imencode + tofile）
cv2.imencode(".jpg", edges)[1].tofile("边缘结果.jpg")
print("已保存 边缘结果.jpg（白线即边缘）")

# 附：把边缘叠加回原图看效果（边缘染红叠回去）
overlay = img.copy()
overlay[edges > 0] = (0, 0, 255)   # 边缘像素涂成红色
cv2.imencode(".jpg", overlay)[1].tofile("边缘叠加.jpg")

阈值怎么调

现象 调法
边缘太碎、噪点满天飞 调高两个阈值（如 100/300），或加大模糊核（5→7）
边缘断断续续、缺失严重 调低两个阈值（如 30/100），或减小模糊
经验法则 t2 : t1 ≈ 2:1 到 3:1，先定 t2 再配 t1

三种边缘算子对比

算子 调用 特点
Canny cv2.Canny(img, 50, 150) 最常用，边缘细且连续，自带双阈值筛选
Sobel cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3) 分 X / Y 方向求梯度，可算方向
Laplacian cv2.Laplacian(img, cv2.CV_64F) 对噪声敏感，通常配模糊用
💡 记忆口诀
边缘检测三板斧：先灰度、再模糊、后 Canny；阈值二比一，碎加高、断调低。

05 摄像头实时目标检测

detect_camera.py：完整可运行代码

# detect_camera.py —— 摄像头实时目标检测（按 q 退出）
import cv2
import time
from ultralytics import YOLO

model = YOLO("yolov8n.pt")

# 0 = 笔记本内置摄像头；外接 USB 摄像头试 1、2；网络摄像头用 rtsp 地址
cap = cv2.VideoCapture(0)

if not cap.isOpened():
    raise RuntimeError("摄像头打开失败，见本章末尾排查表")

# 可选：限制分辨率降低延迟（摄像头支持才行）
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)

prev = time.time()
while True:
    ok, frame = cap.read()
    if not ok:
        print("读取帧失败，摄像头可能被占用")
        break

    # 推理（verbose=False 关掉每帧的刷屏日志）
    results = model(frame, conf=0.4, verbose=False)

    # 拿到画好框的帧
    annotated = results[0].plot()

    # 计算并显示 FPS
    now = time.time()
    fps = 1 / (now - prev)
    prev = now
    cv2.putText(annotated, f"FPS: {fps:.1f}", (10, 30),
                cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 0), 2)

    # 显示画面
    cv2.imshow("YOLO Detection - press q to quit", annotated)
    if cv2.waitKey(1) & 0xFF == ord('q'):  # 按 q 退出
        break

cap.release()
cv2.destroyAllWindows()

# 弹出窗口，你出现在画面里，身上画着 person 框，左上角显示 FPS

换网络摄像头（监控 / RTSP）

海康、大华等网络摄像头都会提供 RTSP 地址，把 VideoCapture(0) 换成地址即可（用户名/密码/IP 按实际改）： 

cap = cv2.VideoCapture("rtsp://admin:密码@192.168.1.64:554/h264/ch1/main/av_stream")

# RTSP 延迟高时：关掉缓冲区，让程序始终读最新帧
cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)

实时检测常见问题

现象 原因 解决方法
摄像头打不开 / isOpented() 为 False 索引不对 / 被占用 / 权限 索引依次试 0、1、2、-1；关掉微信/腾讯会议/其他占用程序；Windows 检查隐私设置里的摄像头权限；Linux 用户加 sudo usermod -aG video $USER
窗口黑屏但没报错 读取了空帧 打印 frame.shape 确认；索引换 cv2.CAP_DSHOW 后端：VideoCapture(0, cv2.CAP_DSHOW)
FPS 只有 2~3，画面卡成PPT CPU 跑不动 / 模型太大 ① 换 yolov8n；② imgsz=320 减小输入；③ 有 GPU 装第 2 章的 GPU 版 torch；④ 隔帧检测（见第 11 章）
RTSP 画面延迟好几秒 OpenCV 缓冲区堆积 CAP_PROP_BUFFERSIZE=1；用子线程单独取帧；或改用摄像头子码流
窗口无响应 / 关不掉 waitKey 没写或参数为 0 必须有 cv2.waitKey(1)（参数是毫秒，写 0 会永久等待按键）
Mac 上报权限错误 终端没拿到摄像头授权 系统设置 → 隐私与安全 → 摄像头 → 勾选你的终端 / VS Code / Python
报 cv2.error 画面尺寸相关 frame 为 None 仍送进推理 在推理前加 if not ok: continue 判断（上面代码已包含）
⚠️ 高频坑：摄像头被占用
cap.isOpened() 为 False 的第一嫌疑永远是别的程序占着摄像头——微信、QQ、腾讯会议、浏览器标签页（某个网页开着摄像头）。全部关掉再试。

06 摄像头实时边缘检测

同一套路：读帧 → 处理 → 显示。这次加一个滑动条实时调阈值，你能直观感受两个阈值的作用。

edge_camera.py：完整可运行代码

# edge_camera.py —— 摄像头实时边缘检测 + 滑动条调阈值（按 q 退出）
import cv2

cap = cv2.VideoCapture(0)
if not cap.isOpened():
    raise RuntimeError("摄像头打开失败")

cv2.namedWindow("Edge")
def nothing(x):
    pass

# 创建两个滑动条：低阈值、高阈值（初始 50 / 150）
cv2.createTrackbar("t1 (low)",  "Edge", 50,  500, nothing)
cv2.createTrackbar("t2 (high)", "Edge", 150, 500, nothing)

while True:
    ok, frame = cap.read()
    if not ok:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)

    t1 = cv2.getTrackbarPos("t1 (low)", "Edge")
    t2 = cv2.getTrackbarPos("t2 (high)", "Edge")
    edges = cv2.Canny(blur, t1, t2)

    # 边缘是单通道图，转回 BGR 才能正常显示（想彩色就取消下面注释）
    show = cv2.cvtColor(edges, cv2.COLOR_GRAY2BGR)

    cv2.imshow("Edge", show)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

拖动滑动条：阈值调到很低时边缘又多又碎，调很高时画面几乎全黑——这就是 Canny 两个参数的全部秘密。

YOLO + 边缘检测结合：只对"人"做边缘检测

一个非常实用的组合技：先用 YOLO 找到人，再只在人的框内做 Canny ——背景的边缘全部消失，只剩目标轮廓。 

# yolo_edge_camera.py —— YOLO 框出人 + 只对框内做边缘检测
import cv2
from ultralytics import YOLO

model = YOLO("yolov8n.pt")
cap = cv2.VideoCapture(0)

while True:
    ok, frame = cap.read()
    if not ok:
        break

    results = model(frame, classes=[0], conf=0.4, verbose=False)  # classes=[0] 只检测 person

    for box in results[0].boxes:
        x1, y1, x2, y2 = [int(v) for v in box.xyxy[0]]
        x1, y1 = max(x1, 0), max(y1, 0)                # 防止越界
        x2, y2 = min(x2, frame.shape[1]), min(y2, frame.shape[0])

        roi = frame[y1:y2, x1:x2]                     # 裁出人所在的区域
        gray = cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY)
        edges = cv2.Canny(cv2.GaussianBlur(gray, (5, 5), 0), 50, 150)

        roi[edges > 0] = (0, 255, 0)                 # 人区域内的边缘涂绿
        cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)   # 画 YOLO 框

    cv2.imshow("YOLO + Edge", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

07 参数调优与结果解读

推理时可调的核心参数

参数 默认 作用 调整建议
conf 0.25 置信度阈值，低于它的框直接丢弃 误检多→调高；漏检多→调低。实时检测建议 0.4~0.5
iou 0.7 NMS 去重的重叠阈值 一个目标出现多个框→调低到 0.45
imgsz 640 推理前缩放到的尺寸 小目标检不到→调大到 1280（更慢）；提速→降到 320/448
classes None 只保留指定类别 classes=[0] 只留 person；[2,5,7] 只留 car/bus-truck
device auto 用哪个设备推理 device='cuda:0' 指定第一块 GPU，'cpu' 强制 CPU
half False 半精度推理（GPU 专属） GPU 上设 half=True，速度翻倍精度几乎不变
max_det 300 单张图最多保留的框数 密集人群场景可调大

漏检 vs 误检：一张表定方向

症状 第一步 第二步 第三步
漏检（目标没框出来） conf 降到 0.2 看是否出现 还漏 → imgsz 加倍 还漏 → 换更大模型（n→s→m）或自己训练
误检（把别的东西框成目标） conf 升到 0.6 还误检 → 加 classes 过滤 还误检 → 训练自己的数据集（第 10 章）

看懂速度日志

0: 480x640 4 persons, 1 bus, 1.2ms preprocess, 15.8ms inference, 1.1ms postprocess

# preprocess  = 图像缩放等预处理耗时
# inference   = 神经网络计算耗时（大头，GPU 加速主要加速它）
# postprocess = NMS 去重等后处理耗时
# 1000 / (inference+前后处理) ≈ 理论最高 FPS

09 按项目需求改代码

真实项目从来不是"检测出框就完事"。下面是六个最常见的需求改造，每个都给出可直接粘贴的代码片段（接在第 5 章 detect_camera.py 的推理循环里）。

需求 1：只检测特定类别（如只统计人）

# 方式 A：推理参数过滤（推荐，不浪费算力在别的类别上）
results = model(frame, classes=[0], verbose=False)   # 0 = person

# 方式 B：拿到结果后再过滤（灵活，可多类）
wanted = {"person", "car"}
for box in results[0].boxes:
    if model.names[int(box.cls[0])] in wanted:
        print("命中目标", box.conf[0])

COCO 80 类常用编号速记：0 person、1 bicycle、2 car、3 motorcycle、5 bus、7 truck、16 cat、17 dog、39 bottle、56 chair、62 tv。完整列表 print(model.names) 一行搞定。

需求 2：人数统计 / 超过 N 人触发告警

results = model(frame, classes=[0], conf=0.5, verbose=False)
count = len(results[0].boxes)          # 当前画面人数

if count > 3:
    # 告警动作：响铃 / 截图存证 / 推送消息，按需替换
    ts = time.strftime("%Y%m%d_%H%M%S")
    cv2.imwrite(f"alarm_{ts}.jpg", frame)   # 保存告警截图
    cv2.putText(frame, f"WARNING! {count} persons", (10, 60),
                cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)
📌 防告警轰炸小技巧
实时画面人数会抖动（16→17→16）。加冷却时间：告警后 30 秒内不再重复告警——一个 last_alarm = 0 时间戳 + if now - last_alarm > 30 判断即可。

需求 3：电子围栏 / 区域入侵检测

只有目标进入指定多边形区域才告警——仓库、工地、机房场景标配。用 cv2.pointPolygonTest 判断目标中心点是否在区域内： 

import numpy as np

# 定义围栏多边形（顶点坐标按你画面里的实际位置改，可用鼠标点击取点）
zone = np.array([[(200, 150), (550, 150), (600, 450), (150, 450)]], dtype=np.int32)

results = model(frame, classes=[0], verbose=False)
for box in results[0].boxes:
    cx, cy, w, h = box.xywh[0].tolist()          # 中心点 + 宽高
    if cv2.pointPolygonTest(zone, (cx, cy), False) >= 0:  # 中心点在区域内
        print("!! 有人闯入围栏区域")

# 把围栏画出来（半透明红色警示区）
overlay = frame.copy()
cv2.fillPoly(overlay, zone, (0, 0, 255))
frame = cv2.addWeighted(overlay, 0.2, frame, 0.8, 0)
cv2.polylines(frame, zone, True, (0, 0, 255), 2)

取顶点坐标的小技巧：先显示一帧画面，绑定 cv2.setMouseCallback 在窗口里点击，把每次点击的坐标 print 出来，依次记录多边形顶点。

需求 4：目标越线计数（进出统计）

商场客流统计的核心：画一条虚拟线，目标中心从上穿到下记 +1，从下穿到上记 -1。用中心点 y 坐标与上一帧的对比判断方向： 

LINE_Y = 300                      # 计数线的 y 坐标
counter = 0
prev_cy = {}                        # 简化演示：按帧粗略追踪（生产建议用追踪器，见下）

results = model(frame, classes=[0], verbose=False)
for box in results[0].boxes:
    cx, cy, _, _ = box.xywh[0].tolist()
    if prev_cy and prev_cy < LINE_Y <= cy:   # 从线上方穿到下方
        counter += 1
    prev_cy = cy

cv2.line(frame, (0, LINE_Y), (frame.shape[1], LINE_Y), (255, 0, 0), 2)
cv2.putText(frame, f"Count: {counter}", (10, 30),
            cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 0, 0), 2)
⚠️ 想做得准，用追踪器
只看坐标会重复计数（同一个人走两步算两次）。ultralytics 自带 BoT-SORT 追踪：results = model.track(frame, persist=True, verbose=False)，然后 box.id 就是每个人的固定编号——按 id 只在第一次越线时 +1。

需求 5：检测结果推送 / 存数据库

检测到目标时调接口或写库（以最常见的"推送到 Web 接口"为例）：

import requests, base64, time

def send_alert(frame, cls_name, conf):
    # 截图转 base64 随请求带上
    _, buf = cv2.imencode('.jpg', frame)
    b64 = base64.b64encode(buf).decode()
    requests.post("http://your-server/api/alert", json={
        "type": cls_name,
        "conf": round(conf, 2),
        "time": time.strftime("%Y-%m-%d %H:%M:%S"),
        "image_b64": b64,
    }, timeout=3)   # 务必设超时，别让网络卡死检测循环

# 在推理循环里：检测到 person 就推一条（配合冷却时间防轰炸）
if "person" in [model.names[int(b.cls[0])] for b in results[0].boxes]:
    send_alert(frame, "person", 0.9)

训练常见问题

现象 原因 解决方法
mAP 很低（<0.3） 数据太少 / 标注质量差 加数据、逐张检查标注漏框错框——数据质量 > 一切调参
训练集很好，验证集很差 过拟合 加数据增强、加数据、减少 epochs；训练集验证集要同分布

loss 剧烈震荡不收敛 学习率过大 / 标注格式错 默认 lr 不用动；检查 txt 是否 5 个值、坐标是否 0~1

11 性能优化与部署

提速四板斧（按性价比排序）

  1. 用小模型：m → s → n，精度换速度最直接的手段
  2. 降输入尺寸：imgsz=320，速度约翻倍，小目标会漏
  3. GPU 半精度：half=True（仅 GPU），白捡近一倍速度
  4. 隔帧检测：每 2~3 帧推理一次，中间帧复用上一次的框——摄像头不怎么动的场景效果拔群 
# 隔帧检测示例：每 3 帧推理一次，速度约 ×3
frame_id = 0
last_annotated = None
while True:
    ok, frame = cap.read()
    if not ok: break
    if frame_id % 3 == 0:                    # 只在 0, 3, 6... 帧推理
        results = model(frame, verbose=False)
        last_annotated = results[0].plot()
    cv2.imshow("demo", last_annotated)
    frame_id += 1

导出部署格式

生产环境不装整套 PyTorch，把模型导出成 ONNX / TensorRT，体更小跑更快： 

# 导出 ONNX（跨平台通用，Windows/Linux 都能跑）
yolo export model=best.pt format=onnx
# 得到 best.onnx，用 onnxruntime 推理，机器上不用装 torch

# 导出 TensorRT（NVIDIA 显卡极限提速，Linux 为主）
yolo export model=best.pt format=engine

# 用 ultralytics 加载 onnx 同样一行（格式自动识别）
model = YOLO("best.onnx")

什么场景选什么方案

场景 推荐方案
学习 / 原型验证 yolov8n + CPU 直接跑，零成本
桌面实时应用 yolov8s + GPU + half=True
Jetson / 树莓派等边缘设备 导出 TensorRT（Jetson）/ NCNN（树莓派）+ n 模型 + 隔帧检测
服务器批量离线分析 大模型 x + 视频批量 predict，精度优先
