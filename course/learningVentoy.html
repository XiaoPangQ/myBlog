Ventoy 重装系统实战指南

一份 Ventoy 从 0 到 1 的完整操作手册：认识原理、安装部署、镜像管理、 BIOS/UEFI 启动、Windows 与 Linux 重装全流程，再到 Secure Boot、插件配置、 多系统维护盘等高阶玩法。一步一步跟着做，就能用 Ventoy 重装任何系统。

1. Ventoy 是什么 & 为什么选它

Ventoy 是国内开发者 longpanda 开源的免费启动 U 盘制作工具。它的核心理念只有一句话：一次安装，反复使用。 装 Ventoy 到 U 盘之后，你只需要把 ISO/WIM/IMG/VHD 等镜像文件直接 复制粘贴 进 U 盘，开机时就能在 Ventoy 菜单里选要启动哪个。

🟢 一句话理解 Ventoy

把 Ventoy 想象成 U 盘版的「启动菜单管理器」：U 盘装一次 Ventoy，以后想换系统镜像就像换电影一样简单——拷进去就能用，删掉就消失。

1.1 Ventoy 的三大优势

🚀
一次制作终身复用

不再每装一次系统就重新格式化 U 盘，不再反复烧录镜像。

💾
U 盘仍是普通 U 盘

数据分区还能正常存文件、拷资料，不影响日常使用。

🌐
支持 1300+ 镜像

Windows 全系、Linux 各发行版、WinPE、PE 救援盘、ChromeOS 等。

1.2 适用场景速查

场景 Ventoy 优势
个人电脑重装 Win10/Win11 免工具，拷 ISO 进去就能装
电脑坏了进 PE 救数据 PE 镜像拷进去就是救援盘
多版本 Linux 装机 一个 U 盘放 Ubuntu/CentOS/Debian
运维批量装机 同一 U 盘 + 自动安装配置文件，可重复刷机
开发测试多系统 随时切换系统镜像，不破坏 U 盘数据
⚠️ 什么时候 Ventoy 不合适

如果你要装的是只有单一镜像的小作坊设备（比如某些品牌机的隐藏恢复分区），或者需要写进 UEFI 隐藏分区的特殊场景，Ventoy 不一定适合，仍推荐用官方工具。

2. 与传统 U 盘工具对比

在 Ventoy 出现之前，做启动盘的工具可以分成「烧录型」和「PE 工具型」两类。Ventoy 属于新一代「引导器型」，思路完全不同。

工具 类型 使用方式 主要缺点
Rufus 烧录型 每次都要选镜像 → 烧录 → 格式化 一盘只能装一个镜像，换镜像就得重来
UltraISO 烧录型 打开 ISO → 写入 U 盘 同上，且对 UEFI 支持差
老毛桃 / 大白菜 PE 工具型 一次性写好 PE，镜像拷进去 大量捆绑推广，主要面向 WinPE
微 PE 工具箱 PE 工具型 同上，但相对干净 只能做 WinPE，多系统支持弱
Ventoy 引导器型 装一次引导器，镜像像文件一样管理 几乎无缺点，开源免费

2.1 Ventoy 装完 U 盘长什么样

安装 Ventoy 后，U 盘会被分成两个分区：

┌───────────────────────────────┬──────────────────────┐
│   Ventoy 引导分区（约 32MB）   │   数据分区（剩余空间）   │
│   隐藏，资源管理器看不到        │   exFAT，可在资源管理器  │
│   装着 Ventoy 启动管理器        │   操作，像普通 U 盘      │
│   ❌ 不要手动修改或删除         │   ✅ 镜像直接复制到这里    │
└───────────────────────────────┴──────────────────────┘
🟢 重要认知

Ventoy 安装到 U 盘后，U 盘里看到的那个分区就是数据分区，ISO 文件都放这里面；引导分区是隐藏的，不要动它、不要格式化它、不要用 Diskpart 删它。

3. 准备工作 & 选对 U 盘

这一步做错，后面所有步骤都白搭。Ventoy 安装过程会格式化整个 U 盘，所以先确认硬件和数据都准备好了。

3.1 必备清单

  1. 一台正常工作的电脑（Win10/Win11/Linux/macOS 都行）。
  2. 一个空 U 盘，建议 USB 3.0 接口 + 16GB 以上，质量靠谱的品牌 U 盘（金士顿/闪迪/三星/海康威视等）。
  3. 下载 Ventoy 安装包：去 ventoy.net 或 GitHub Releases 下载对应系统的最新版本（2026-09 最新为 Ventoy 1.1.17，2026-07-24 发布）。
  4. 下载系统镜像：Win10/Win11 ISO、Ubuntu ISO 或 WinPE 镜像（第六章会讲）。
🔴 备份！备份！备份！

Ventoy 安装会清空 U 盘上的全部数据，格式化后数据基本无法恢复。U 盘里如果有重要文件，必须先备份到电脑或另一块硬盘，这一步不能省。

3.2 U 盘选择建议

使用场景 推荐容量 说明
只装 Win11 一个镜像 8GB 起 Win11 ISO 约 6GB，留点富余
Win10 + Win11 + 一个 Linux 32GB 三个镜像加起来 15GB 左右
多系统维护盘（Win + Linux + PE + 工具） 64GB+ 装机 + 救援两用
USB 2.0 U 盘 不建议 启动慢、读盘卡顿，会拉低 Ventoy 体验
杂牌扩容盘 不建议 质量不稳，启动容易翻车

3.3 Ventoy 下载渠道

  1. 打开浏览器，访问 ventoy.net（官网，已自动跳转 GitHub Releases）。
  2. 选择最新版本，下载对应系统的安装包：
    • Windows 用户：ventoy-1.1.17-windows.zip
    • Linux 用户：ventoy-1.1.17-linux.tar.gz
    • macOS 用户：ventoy-1.1.17-mac.tar.gz
  3. 解压到任意目录（如 D:\Tools\Ventoy），解压后看到 Ventoy2Disk.exe（Windows）或 ventoy_install.sh（Linux）就算成功。
🟢 下载避坑

网络上搜索 Ventoy 经常会出现各种「绿色版」「破解版」捆绑软件。务必只从 ventoy.net 或 github.com/ventoy/Ventoy 下载官方原版，不要下第三方修改版。

4. 安装 Ventoy 到 U 盘

这是整个流程的核心一步。本章以 Windows 为例详细讲解，Linux 和 macOS 操作几乎相同。

4.1 Windows 安装步骤

  1. 插入 U 盘，等待系统识别。
  2. 打开解压后的 Ventoy 文件夹，右键 Ventoy2Disk.exe → 以管理员身份运行。
  3. 在 Ventoy2Disk 主界面，设备下拉框里选中你的 U 盘（看容量、盘符确认）。
  4. 点击左下角 「选项」，确认几个关键设置（4.2 节会展开）：
    • 分区表类型：MBR（兼容老电脑） / GPT（新 UEFI）
    • 数据分区文件系统：exFAT（默认，推荐）
    • Secure Boot Support：勾选（默认）
  5. 点击 「安装」 按钮，弹出确认窗口（会明确告知「设备将被格式化，数据会丢失」），再次确认盘符正确后点确定。
  6. 等待进度条跑完，出现「安装成功」提示后关闭窗口，整个过程通常只要 1-2 分钟。
🔴 选盘红线和救命口诀

这是整个 Ventoy 流程最危险的环节：选错盘符点安装，会把电脑硬盘的分区表和数据全毁了。必须遵守三条铁律：

  • ❌ 不要勾选「Show All Devices」（会暴露电脑内置硬盘）
  • ✅ 只插一个 U 盘再操作，避免误选
  • ✅ 按「容量 + 型号 + 拔出再看」三步确认：选中后看容量是不是 U 盘大小、拔出 U 盘看下拉框是不是空了

4.2 关键选项详解

选项 推荐值 说明
分区表 MBR / GPT MBR（兼容性强） MBR 同时支持 Legacy BIOS 和 UEFI 老电脑；GPT 只支持纯 UEFI 装机机（2012 年后电脑基本都是 UEFI）
数据分区文件系统 exFAT 支持超过 4GB 的单文件（Win11 ISO 就 6GB），跨平台支持好。FAT32 有 4GB 限制不推荐；NTFS 在某些 Linux 启动会出问题
Secure Boot Support 勾选 开启后支持 Win11 默认的 Secure Boot，第五章详细讲
分区对齐（对齐到 4KB） 默认 提升 SSD/U 盘性能，保留

4.3 Linux 安装（Ubuntu/Debian 为例）

# 1. 解压并进入目录
tar -xzf ventoy-1.1.17-linux.tar.gz
cd ventoy-1.1.17

# 2. 确认 U 盘设备名（看容量判断）
lsblk
# 比如看到 sdb 8G → /dev/sdb 是 U 盘

# 3. 安装（⚠️ 一定要选对设备名）
sudo ./Ventoy2Disk.sh -i -g /dev/sdb
# -i 表示 install，-g 表示 GPT 分区表
# 想用 MBR 就去掉 -g

# 4. 等待完成，看到「Install Ventoy to /dev/sdb successfully」就 OK

4.4 安装后验证

  1. 打开文件资源管理器，能看到 U 盘分区（容量与原始 U 盘一致）。
  2. 右键 U 盘 → 属性，确认文件系统是 exFAT。
  3. 尝试拖一个普通文件进去，能正常读写就 OK。
  4. （可选）打开磁盘管理（diskmgmt.msc），应该看到 U 盘有两个分区：一个未分配的小分区（隐藏引导），一个大分区（数据区）。
⚠️ 看不到引导分区是正常的

Ventoy 引导分区被故意做成隐藏的，资源管理器看不到。千万不要用 Diskpart 的 clean 命令去「清理」这个隐藏分区，否则 Ventoy 就废了。

5. Secure Boot 安全启动配置

Win11 默认开启 Secure Boot（安全启动），Win10 现代模式也常开。如果 Ventoy 没启用 Secure Boot 支持，进系统时会卡在蓝屏报错 Security Boot Violation。

5.1 Ventoy 端：开启 Secure Boot 支持

Ventoy 安装时默认已勾选 Secure Boot Support。如果你已经安装但没勾选，无需重装，可以用「升级」功能重新写引导：

  1. 再次以管理员身份运行 Ventoy2Disk.exe，选中你的 U 盘。
  2. 此时界面会显示 「升级」 按钮（不是「安装」），点升级即可。
  3. 升级只更新引导区，U 盘里的镜像文件全部保留，不会丢数据。

5.2 首次启动：注册 Ventoy 密钥

第一次从 Ventoy U 盘启动并开启 Secure Boot 时，会进入一个蓝色 MOK 管理界面：

  1. 开机进入 Ventoy 菜单前，弹出 MOK Management 蓝屏。
  2. 选择 「Enroll Key from Disk」（从磁盘注册密钥）。
  3. 选择 ENROLL_THIS_KEY_IN_MOKMANAGER.cer 文件（Ventoy 自带）。
  4. 按提示继续，选择 「Continue」 → 「Yes」，可能要求输入临时密码（按屏幕提示操作）。
  5. 完成后重启，Secure Boot 就能识别 Ventoy 了。这个步骤只需做一次，之后启动会自动跳过。
🟢 MOK 密钥文件在哪

Ventoy 的 MOK 密钥文件 ENROLL_THIS_KEY_IN_MOKMANAGER.cer 放在 Ventoy 隐藏引导分区里。MOK 管理界面会自动列出，直接选即可，不需要你自己去 U 盘找。

5.3 BIOS/UEFI 端：确认开启 Secure Boot

如果上面步骤都做了还是进不去，需要进 BIOS/UEFI 检查：

  1. 开机按对应键进 BIOS（第八章有详细按键表）。
  2. 找到 Secure Boot 选项（一般在 Security / Boot / Authentication 菜单下）。
  3. 确认状态是 Enabled（开启）。
  4. 保存退出（一般按 F10 → Yes）。
⚠️ Secure Boot 装完系统后怎么办

有些用户嫌 Secure Boot 麻烦会直接关掉，不建议这样做：Secure Boot 能防止恶意引导程序，是 Win11 的安全屏障之一。除非你明确知道自己在做什么，否则保持开启。

6. 准备系统镜像（Win/Linux/PE）

Ventoy 只负责启动，不管镜像对不对。镜像必须自己去下载，而且下载来源和版本必须靠谱，否则装出来的系统会带一堆广告或根本用不了。

6.1 Windows 镜像下载

系统 推荐下载源 说明
Windows 11 官方原版 微软官网 microsoft.com/software-download/windows11 使用「媒体创建工具」下载，或直接下 ISO
Windows 10 官方原版 微软官网 microsoft.com/software-download/windows10 同上
Windows Server microsoft.com/evalcenter 评估版可用于学习，180 天试用
❌ 第三方修改版（GHOST/ghostxp/总裁版） 不要用 带全家桶广告 + 后门 + 篡改系统，强烈不推荐
🟢 推荐下载工具

微软提供官方「媒体创建工具」（MediaCreationTool），会自动选最新稳定版 ISO。优先用官方工具，下载链接会跟随最新版走，不会下到旧版。

6.2 Linux 镜像下载

发行版 推荐下载源 适用场景
Ubuntu Desktop / Server ubuntu.com/download 最流行的桌面/服务器发行版
Debian debian.org/distrib 稳定性优先
CentOS Stream / Rocky / Alma 各官网 服务器首选 RHEL 系
Fedora getfedora.org 新特性尝鲜
Arch Linux archlinux.org/download 深度玩家
Kali kali.org/get-kali 安全测试专用

6.3 WinPE 镜像（救援盘）

WinPE 是一个极简版 Windows，从 U 盘启动后只有桌面 + 文件管理器，适合救数据 / 备份 / 改密码 / 修引导等维护操作。推荐两个干净的：

PE 工具 特点 下载
微 PE 工具箱 2.x 国内主流，干净无捆绑 wepe.com.cn
Edgeless 插件化，可加载常用工具 edgeless.top
Hiren's BootCD PE 国外老牌，集成大量工具 hirtstudio.com
❌ 老毛桃 / 大白菜 / 电脑店 大量捆绑 + 篡改主页 不要用
🔴 PE 选择红线

网络上 90% 的「PE 工具」都会捆绑流氓软件、篡改浏览器主页。只用上面表格里列出的「干净 PE」，其他 PE 一律不要碰。这条线比镜像本身还重要。

6.4 镜像文件命名建议

Ventoy 会按文件名排序显示镜像，建议按版本号+日期命名，方便日后区分： 

Win11_23H2_zh-cn_2026-08.iso
Win10_22H2_zh-cn_2026-07.iso
Ubuntu_24.04_desktop_amd64.iso
WePE_2.3.iso
Hirens_BootCD_PE.iso

7. 拷镜像到 U 盘 & 验证

Ventoy 安装完成后，U 盘就像普通 U 盘一样用。这一步就一句话：把镜像文件复制粘贴进去。

7.1 拷镜像的三种方式

方式 操作 适用
文件资源管理器拖拽 打开 U 盘，把 ISO 文件拖进去 最简单，推荐
命令行复制 copy D:\Downloads\Win11.iso E:\ 批量或写脚本
rsync / cp Linux 下命令行复制 Linux 服务器

7.2 文件夹组织（可选）

如果 U 盘里镜像很多，可以建子文件夹分类。Ventoy 会显示树形菜单：

U 盘根目录
├── Windows/
│   ├── Win11_23H2_zh-cn.iso
│   └── Win10_22H2_zh-cn.iso
├── Linux/
│   ├── Ubuntu_24.04_desktop.iso
│   └── Debian_12.iso
└── PE/
    └── WePE_2.3.iso

启动时按 F1 键可在「List Mode」和「TreeView Mode」之间切换，TreeView 能看到完整目录树。

7.3 验证 U 盘就绪

  1. 打开 U 盘，确认 ISO 文件已经拷贝完成（看文件大小是否等于原文件大小）。
  2. （推荐）右键 ISO → 属性 → 看「大小」是不是 5GB 以上的整数倍（确保没拷贝中途失败）。
  3. 弹出 U 盘，安全拔除。
⚠️ 文件拷进去但 Ventoy 不识别？

99% 的情况是文件后缀不对。Ventoy 通过文件后缀识别镜像格式，必须是 .iso / .wim / .img / .vhd / .vhd.x / .efi 之一。如果你下的是 .img.gz / .iso.zip，得先解压。

7.4 Ventoy 支持的镜像格式

格式 用途
.iso 最常见，Windows / Linux / PE 都是
.wim Windows 映像格式（WinPE 通常）
.img 类 Unix 系统镜像，部分 Linux
.vhd / .vhdx 虚拟机磁盘，部分 Windows To Go
.efi 纯 UEFI 启动镜像
.iso.gz / .iso.xz 压缩镜像，部分 Linux（小镜像常用）

8. 进 BIOS/UEFI & 选择 U 盘启动

Ventoy U 盘准备好了，下一步就是从 U 盘启动。但很多人卡在第一步——不知道按哪个键进启动菜单。

8.1 两个概念：BIOS vs UEFI

概念 BIOS（Legacy） UEFI
界面 蓝底白字，传统菜单 图形化 + 鼠标，新式
分区表 MBR GPT
硬盘大小 最大 2TB 支持无限
启动速度 慢 快
Secure Boot 不支持 支持
2012 年后 几乎都是 UEFI 主流

品牌 启动菜单键 BIOS 进入键
华硕 ASUS F8 DEL / F2
技微 Gigabyte F12 DEL

联想 Lenovo（笔记本） F12 / Fn+F12 F2 / Novo 按钮
戴尔 Dell F12 F2

🟢 找启动键的 3 个技巧

  • 实在不知道，全部都试：F2/F12/F8/DEL/ESC 挨个按，BIOS/启动菜单一定会进一个
  • 看屏幕第一行小字：主板厂商会把「Press F12 to enter Boot Menu」写在开机画面最底下

8.3 在启动菜单里选对 U 盘

进入启动菜单后，通常会列出多个 USB 设备，选带「UEFI:」前缀的那个（UEFI 模式），如果你的 Ventoy 用了 MBR 分区表，也可以选不带 UEFI 前缀的 USB 设备：

SanDisk Ultra Fit 1.00

→ 选第一项「UEFI: SanDisk Ultra Fit 1.00」 ✅

8.4 开机直接跳过 U 盘的解决方法

如果插了 Ventoy U 盘但启动菜单里看不到：

  1. 先进 BIOS，确认 USB Boot 或 USB Storage 选项是 Enabled。
  2. 确认 Boot Mode 是 UEFI（不要选 Legacy Only，否则可能不识别 Ventoy 的 UEFI 引导）。
  3. 如果电脑有 Fast Boot / 快速启动，临时关掉，避免跳过 USB 设备检测。
  4. 换 USB 口试试（优先用后置 USB 3.0 口）。
  5. 换一根 USB 数据线/换另一个 U 盘，排除接触不良。

9. Windows 重装实战

从 Ventoy 菜单选好 ISO 回车后，正式进入系统安装流程。本章以 Windows 11 为例，Win10 几乎相同。

9.1 Windows 重装的标准流程

  1. 选好语言和输入法：简体中文 / 中国（简体）键盘。
  2. 点「现在安装」。
  3. 输入产品密钥：没有就点「我没有产品密钥」继续。Win11 重装会自动读取主板 OEM 密钥，联网后自动激活。
  4. 选版本：家庭版 / 专业版（一般选专业版）。
  5. 勾选许可条款。
  6. 选安装类型：选「自定义：仅安装 Windows（高级）」，这是全新安装。
  7. 磁盘分区（重点）：
    • 看到磁盘列表，每个盘会显示「驱动器 0 分区 1」之类。
    • 如果电脑已有系统，把系统盘的所有分区全删掉（选中 → 删除），让它变成「未分配的空间」。
    • 如果装双系统，选未分配空间点「下一步」即可，别动其他系统盘。
    • 点「下一步」开始安装。
  8. 等待文件复制 + 重启 + 完成 OOBE 初始设置。
🔴 分区操作红线
  • 如果是要重装同一个磁盘上的系统，才能全删该磁盘分区
  • 如果电脑里有另一块硬盘存数据，千万别动那块硬盘的分区
  • 没看清楚盘符之前不要乱点，删错分区=数据全毁

9.2 Ventoy 下的快捷安装小技巧

  • Ventoy 启动后按 F5 键（部分版本是 F2）可以进入二级菜单，针对特定 ISO 选择不同启动模式（Normal / WIMBOOT / GRUB2 等）。
  • 装 Win11 出现「这台电脑不满足 Win11 最低要求」时，可以在 Ventoy 菜单选 ISO 时按 F5，启用 WIMBOOT 模式（绕过 TPM 2.0 检查，老电脑也能装）。
  • 用 Ctrl+W 切换 WIMBOOT 模式（仅 Windows 标准安装镜像有效）。

9.3 安装完后的必做事项

  1. 联网让 Windows 自动激活。
  2. 装驱动：建议用「驱动人生网卡版」或「鲁大师」先识别网卡，再补齐其他驱动。
  3. Windows Update 把所有更新打完。
  4. 装常用软件（7-Zip / Chrome / VS Code / WPS 等）。
  5. 备份一份 Ventoy U 盘（11.4 节会讲 Ventoy 升级与备份）。

10. Linux 重装实战

Linux 用 Ventoy 安装比 Windows 更简单，但分区方案不一样。本章以 Ubuntu 24.04 Desktop 为例。

10.1 Linux 安装流程

  1. 从 Ventoy 菜单选 Ubuntu ISO 回车，默认选第一项「Try or Install Ubuntu」。
  2. 进入 Live 系统（可以先体验，不点 Install 不会动硬盘）。
  3. 双击桌面 「Install Ubuntu」 图标开始安装。
  4. 选语言 → 选键盘布局 → 选安装类型（「正常安装」+「安装时下载更新」+「安装第三方软件」三个都勾选最省心）。
  5. 关键一步：磁盘分区：
    • 新手选 「清除整个磁盘并安装 Ubuntu」（最简单）。
    • 老手选 「其他选项」手动分区（10.2 节展开）。
  6. 设置时区（默认上海就行）、用户名、密码。
  7. 等待安装完成，提示重启。
  8. 重启前拔掉 U 盘，避免再次进入 Ventoy 菜单。

10.2 手动分区方案（推荐）

如果选择「其他选项」手动分区，建议的最小分区方案：

挂载点 大小 文件系统 说明
/boot（UEFI 系统用） 512MB - 1GB ext4 启动分区
EFI 系统分区（已有则跳过） 100-500MB FAT32 UEFI 启动文件
swap 交换分区 内存等大或 2-4GB swap 内存不足时备用
/（根分区） 剩余空间 ext4 系统 + 软件
/home（可选） 独立分区 ext4 个人文件，重装不丢

10.3 与 Windows 双系统

双系统安装的关键是先装 Windows 再装 Linux：

  1. 先正常装好 Windows，确认能进系统。
  2. 插 Ventoy U 盘重启，从 Ventoy 启动 Linux ISO。
  3. 安装 Linux 时选择「其他选项」手动分区，不要动 Windows 所在的 NTFS 分区，把空闲空间分给 Linux。
  4. Linux 安装器的引导加载器（GRUB）会自动识别 Windows，重启后会看到双系统选择菜单。
⚠️ 双系统引导修复

如果装完 Linux 后 Windows 引导丢了，开机直接进 Linux，可以从 Linux 终端运行： 

sudo update-grub
# 或手动修复
sudo os-prober  # 扫描其他系统
sudo grub-install /dev/sda  # 重装 GRUB 到主硬盘

10.4 Ventoy 的 Linux 进阶用法

  • 选 Linux ISO 时按 Tab 键（UEFI 模式）或 e 键（Legacy 模式）可编辑启动参数，比如 nomodeset（显卡驱动翻车时禁用）。
  • Linux ISO 放在子目录也支持，Ventoy 会自动扫描整个数据分区。
  • 部分 Linux 启动需要 GRUB2 模式：选 ISO 后按 F5 → 选 GRUB2 Mode。

11. 进阶玩法：插件、密码、自动安装

Ventoy 不只是一个启动器，它还有一整套插件体系，让你对启动行为做精细控制。

11.1 Ventoy 插件体系简介

Ventoy 插件通过 ventoy.json 配置文件控制，文件放在 U 盘数据分区根目录。最常用的几个插件：

插件 功能 典型用途
theme 自定义启动菜单主题 换皮肤、加 LOGO
auto_install 全自动应答式安装 批量无人值守装机
persistence Linux 持久化存储 Live USB 启动后修改的数据保留
password Ventoy 菜单加密码 防止别人拿你的 U 盘乱装系统
image_blacklist 黑名单隐藏某些镜像 隐藏私密镜像
file_injection 启动时注入文件 提前塞入驱动、配置文件

11.2 启动密码配置

担心别人拿走 U 盘乱装系统？给 Ventoy 菜单加个密码：

  1. 在 U 盘数据分区根目录创建 ventoy/ventoy.json 文件（没有 ventoy 文件夹就新建）。
  2. 写入以下配置：
{
  "control": [
    { "VTOY_DEFAULT_SEARCH_ROOT": "/ISO" }
  ],
  "theme": {
    "file": "/ventoy/themes/blak/theme.txt",
    "ventoy_left": "5%",
    "ventoy_top": "85%"
  },
  "password": {
    "type": "plain",
    "password": "your_strong_password"
  }
}

启动时 Ventoy 会要求输入密码，输错不让进菜单。

⚠️ 密码忘了怎么办

密码配置错了或忘了，可以用 Ventoy2Disk 升级功能重新生成 ventoy 目录，会清掉所有 ventoy.json 自定义配置。所以密码别设太复杂，写在小本子上。

11.3 自动安装（Auto Install）

批量装机的神器：把 Ventoy U 盘插上，开机后完全无人值守自动装完系统。需要给 Windows 准备 autounattend.xml 应答文件，给 Linux 用 Kickstart / Preseed 文件。

Ventoy 自动安装配置示例：

{
  "auto_install": [
    {
      "image": "/Win11_23H2_zh-cn.iso",
      "template": "/ventoy/autounattend.xml"
    }
  ]
}

把对应的应答文件路径填到 template 字段，启动时 Ventoy 会自动注入到安装流程里。autounattend.xml 的生成可以用微软的「Windows 映像和配置设计器 (Windows ICD)」，或者从网上找现成的修改。

11.4 VentoyPlugson 图形配置器

手写 JSON 太累？Ventoy 官方提供了 VentoyPlugson 图形化插件配置器：

  1. 从 ventoy.net 下载 VentoyPlugson（与主程序同版本号）。
  2. 解压，运行 VentoyPlugson.exe。
  3. 它会启动一个本地 Web 服务（默认端口 8881），浏览器打开 localhost:8881。
  4. 通过网页表单勾选配置，导出 ventoy.json 文件到 U 盘。
🟢 升级 Ventoy 不丢数据

Ventoy 升级是「无损升级」：

  1. 下载新版本 Ventoy。
  2. 运行 Ventoy2Disk，选中 U 盘。
  3. 点 「升级」（不是「安装」）。
  4. 升级只更新引导区，U 盘里的镜像和数据全部保留。

所以建议每 3-6 个月升级一次，跟上最新版（最新版修复的 bug 很多）。

11.5 多系统维护盘最佳实践

把 Ventoy 打造成装机 + 救援两用 U 盘：

U 盘目录结构建议（64GB+）：

├── Windows/
│   ├── Win11_23H2_zh-cn.iso          ← 主力装机镜像
│   └── Win10_22H2_zh-cn.iso          ← 老机器备用
├── Linux/
│   ├── Ubuntu_24.04_desktop.iso     ← 日常 Linux
│   └── Debian_12_netinst.iso         ← 极简服务器装
├── PE/
│   ├── WePE_2.3.iso                  ← 救数据首选
│   └── Hirens_BootCD_PE.iso         ← 工具集成救援
├── Tools/
│   ├── DiskGenius_x64.ico         ← 单独工具（可启动 ISO）
│   └── MHDD_bootable.iso            ← 硬盘检测
└── ventoy/
    └── ventoy.json                  ← 插件配置

12. 报错速查 & 验证清单

最后这一章是给你卡住时救命用的。把报错现象对号入座，找到对应原因和解决办法。

12.1 安装阶段报错

现象 原因 解决办法
Ventoy2Disk 找不到 U 盘 U 盘没插好 / 驱动问题 换 USB 口重插；重启软件；以管理员身份运行
安装时报「设备被占用」 U 盘里有文件被占用（如资源管理器打开） 关闭所有 U 盘窗口，安全弹出后再插
安装到一半失败 / 进度卡住 U 盘质量差 / 接触不良 换一根 USB 线；换一个 U 盘
安装时报「写保护」 U 盘有写保护开关（部分老 U 盘有） 检查 U 盘侧面物理开关；换 U 盘
误装到电脑内置硬盘 选错盘符 ⚠️ 立即停止操作，找专业数据恢复，不可逆

12.2 启动阶段报错

现象 原因 解决办法
插 U 盘启动菜单里看不到 USB USB Boot 关闭 / Fast Boot 开启 进 BIOS 开启 USB Boot、关闭 Fast Boot
选 U 盘后黑屏 / 光标闪烁 UEFI 模式与镜像不匹配 在启动菜单里换另一个 USB 设备（带/不带 UEFI 前缀都试）
进 Ventoy 后菜单不显示镜像 镜像文件后缀不对 / 文件损坏 检查后缀是否为 .iso/.wim 等；重新下载校验 SHA256
Security Boot Violation（蓝屏） Secure Boot 没注册 Ventoy 密钥 重新用 Ventoy2Disk 升级一次，开启 Secure Boot Support
MOK Management 进不去 UEFI 固件版本老 更新主板 BIOS；或在 BIOS 临时关闭 Secure Boot
卡在「Booting...」长按无反应 镜像与 Ventoy 不兼容 / 镜像过大读不动 换 USB 3.0 口；选 F5 二级菜单换启动模式
卡在 GRUB 提示符 某些 Linux 镜像需要手动引导 输入 exit 回车回到 Ventoy 菜单；换启动模式

12.3 安装阶段报错

现象 原因 解决办法
Win11 安装提示「不满足最低要求」 TPM 2.0 / Secure Boot 不通过 Ventoy 菜单选 ISO 后按 F5 选 WIMBOOT 模式绕过
Windows 安装找不到硬盘 缺少磁盘驱动（NVMe / RAID） 下载对应 RAID/NVMe 驱动，放到 U 盘，安装器加载驱动
Linux 安装卡在「检测文件系统」 Windows Fast Startup 残留的休眠分区 先进 Windows 关闭快速启动，或在 Linux 手动分区跳过
装完系统重启还是进 Ventoy 忘了拔 U 盘 关机 → 拔 U 盘 → 再开机
装完系统找不到引导 BIOS 启动顺序不对 进 BIOS 把系统硬盘调到第一启动项

12.4 完整验证清单（制作后必做）

  1. ✅ Ventoy 安装成功，U 盘数据分区能正常读写
  2. ✅ 文件系统是 exFAT（看 U 盘属性）
  3. ✅ 至少拷了一个 ISO 镜像到 U 盘
  4. ✅ 用任意一台电脑从 U 盘启动，能看到 Ventoy 菜单
  5. ✅ Ventoy 菜单能列出 U 盘里的镜像文件
  6. ✅ 选中 ISO 回车能正常进入系统安装界面
  7. ✅ Secure Boot 环境下不报 Security Boot Violation（首次需注册密钥）
  8. ✅ 装完系统能正常进入新系统（拔 U 盘后）

12.5 Ventoy 口诀总结

📌 十二句口诀
  1. 官方下载：Ventoy 只从 ventoy.net 或 github 拿，其他都是流氓版
  2. 备份先行：安装会清盘，重要数据先存出去
  3. 只插一盘：操作时只插目标 U 盘，防误选硬盘
  4. 三看选盘：看容量、看型号、拔出确认下拉框空了
  5. exFAT 默认：别用 FAT32，超 4GB 文件装不下
  6. Secure Boot 开启：首次启动进 MOK 注册密钥，只做一次
  7. 只认 ISO 等格式：.iso/.wim/.img/.vhd/.efi，其他后缀不识别
  8. 狂按启动键：F2/F12/F8/DEL 不知道就挨个试
  9. 选 UEFI: 前缀：UEFI 启动菜单里找带 UEFI 的 U 盘项
  10. 分区别乱删：重装系统只删系统盘分区，数据盘别动
  11. 升级无损：新版 Ventoy 用「升级」按钮，镜像数据全保留
  12. VentoyPlugson：插件配置用图形工具，别手写 JSON

按这十二句口诀对照检查，Ventoy 重装系统这件事就能稳稳拿下。指南到这里就结束了，祝你装机愉快。
